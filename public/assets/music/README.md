# 本地音乐文件夹指南

本目录支持两种方式批量管理你的 MP3 曲库：

1. **网页端管理员直接导入（推荐）**：
   访问站内 `/admin/` → 「音乐管理」，点击 **「导入整个 MP3 文件夹」**，直接选中你电脑里装满 `.mp3` 的文件夹。网页会自动读取歌曲 ID3 标签中的**歌名、歌手、时长与内嵌封面（自动压缩为 WebP）**，并一键推送到 GitHub 仓库触发重建。
2. **本地复制文件夹直出**：
   将 `.mp3` / `.m4a` / `.ogg` / `.flac` / `.wav` 文件直接放进 `public/assets/music/url/`（支持按 `歌手 - 歌名.mp3` 命名，也支持子目录）。构建时会自动扫描本目录并合并进播放器歌单；同名封面可放在 `public/assets/music/cover/<歌名>.webp` 或同级目录。
